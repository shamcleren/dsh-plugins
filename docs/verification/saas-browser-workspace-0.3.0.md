# SaaS Browser Workspace 0.3.0 验收

本次是独立临时 Web profile 中的实验插件验收，宿主固定为官方 0.2.1-rc.5。通过打包 tarball 和官方 CLI 安装、更新；未修改官方源码、未更新用户已有安装、未发布 catalog 包。

## 实现范围

- 复用 BrowserService、原生模型与会话队列、GenUI 表单、右侧面板和原页面弹框。
- 显式注册调试和使用的来源、路径、聊天容器、消息输入、发送、回复、运行与错误控件。默认关闭执行；配置编辑、保存、发布等动作始终拒绝。
- 接续页面实际打开的使用窗口，先将初始 HTTP 导航升级到已授权 HTTPS，再做入口校验；未注册入口在网络发出前拒绝。
- 单次发送有唯一标识，发送前记录收据。只展示本次新增的页面回复，区分运行中、完成、失败和待确认；超时不自动重发。
- 私有收据按会话与站点隔离；恢复时保留完成结果，未确认执行不重发。界面能识别工作台重启后新的状态版本。

## 已通过

- TypeScript 严格检查、服务端与客户端构建。
- 6 个测试文件、27 项测试。新增覆盖延迟回复、真实错误、重复发送、配置保护、跨来源窗口、HTTP 窗口升级、执行收据恢复和中断处理、界面版本更新，以及空白页面不读取内联脚本。
- 新包经官方 CLI 安装与真实宿主启动。
- 真实 Grok 生成共用消息表单；在 DSH 界面填写并提交后，同一 Agent 继续执行。
- 真实目标的预览调试完成，简单算术问题得到真实回复 `42`；对应输入、输出、状态展示在右侧。已完成收据保留，未重复调试。
- 同一 Agent 通过实际“去使用”按钮打开应用，发送相同问题并获得真实回复 `42`。右侧同时展示两条完成结果，原页面弹框也显示实际使用回复。
- 两条流程各发送一次；刷新配置页核对，保存时间与执行前相同。

## 边界

- 依赖站点选择器，不代表任意网站泛化；不覆盖文件上传、复杂参数控件、多人共享、完整重启恢复或桌面应用壳。
- 结果完成判断依赖注册区域的新增回复及运行/错误状态。原网站的对话记录、计费和记忆行为仍由原网站控制。
- 真实配置、执行审计和截图仅保存在本机私有目录。
