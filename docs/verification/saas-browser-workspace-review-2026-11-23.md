## 用户可以感知的交互变化

1. **知道现在做到哪一步。** 区分准备、排队、执行、补参、人工接管、失败和断连；不将模型停止等同于业务执行成功。
2. **补参后能可靠继续。** 使用实际 GenUI 表单，支持多行输入、必填约束和可选参数跳过；快速双击不会重复入队。
3. **视图来回切换不丢上下文。** 保留当前会话最近查询、已读配置和执行结果；清楚显示当前选择、数据来源、读取时间、统计范围与截断提示。这不是完整历史查询库。
4. **原页面接管有明确边界。** 登录时仅在进入登录状态时弹出，不因轮询抢焦点；断流提示、暂停输入、交还后撤销旧输入；Esc 关闭，Shift+Tab 可离开远程画面。
5. **按钮与可用能力一致。** 调试/使用按站点配置出现，未选择或执行中不能重复操作；未配置站点及连接失败都有可行动的说明。
6. **窄侧栏可操作。** 400px 宽度下页面没有横向溢出，表格内部滚动；长文本、多行表单、焦点和按钮状态经过浏览器检查。

## 三项质量结论与剩余边界

- **功能非预期退化：本地回归及完整官方宿主真实模型验收通过，真实业务站点最新版待试用。** 既有查询、选择、配置只读、调试/使用执行与去重测试仍通过；本轮未修改或操作真实业务配置。上次真实站点结果保留在 [首次 0.3.0 验收](saas-browser-workspace-0.3.0.md)，不转记为本轮修订的通过证据。
- **性能：针对性机制检查通过，生产性能未测。** 双订阅共用一条串行状态轮询，相同 revision 不触发重复发布，历史列表和详情不再随每个工具结果重复进入模型上下文。页面文本、记录数和收据有上限；没有生产吞吐或尾延迟测量，不报告推算的提升百分比。
- **新增分支：关键代表性回归通过，全量覆盖率未测。** 上表覆盖高风险竞态、拒绝、恢复、异常和生命周期路径；没有全量 branch coverage 百分比，不宣称覆盖所有网站状态或所有组合。

当前仍依赖站点选择器与来源登记，最多读取当前 DOM 的50条记录；未提供任意网站自动适配、完整任务重启恢复、多用户共享、复杂文件与编辑器交互。原页面使用连续 JPEG 画面，不是完整远程桌面。

已确认缺陷均有修复与回归证据。最新候选在真实业务站点上的验证交由用户本地试用；不自动变更正式安装。
