# Security Scan 0.15.0 发布候选验证

日期：2026-11-06。环境：macOS arm64；官方 DSH 0.2.1-rc.5。此记录对应本地发布候选，不表示已对外发布或更新现有用户安装。

2026-11-09 补注：合成评测语料、基线和 `evaluate` 命令已从当前源码移除，原因是样例中的刻意漏洞代码触发仓库安全扫描。以下检查和包内容仅记录 0.15.0 当时的结果。

## 变更

- 保留 0.14 的标准侧栏面板与草稿恢复；全局及临时审计工具统一为 `dsh_security_scan_` 前缀，Skill 为 `dsh-security-review`，不占用通用旧名。Profile 配置、preset 和已有数据格式不改名。迁移表在 [组件 README](../../plugins/security-scan/docs/guide.md#015-工具命名迁移)。
- 新增 uv.lock schema v1 TOML 解析；锁定 registry 版本、环境分支、工作区包及不支持来源的行为与边界见组件 README。新增生产依赖固定为 smol-toml 1.9.1，含完整性锁及 BSD notice。
- 当时随包提供公开合成语料、逐例结果、混淆矩阵、语言/CWE 分组、语料/规则摘要和可复跑 CLI；这些评测资产与入口已从当前源码移除。
- 补齐中英文使用说明、命名迁移、贡献指南、安全反馈和第三方许可说明；明确静态扫描、可选 AI 源码审计与 DAST 的区别。默认 AI 开启及外层聊天的 Token 消耗分别说明。
- 发布包测试发现并修复 CLI 在 npm bin / macOS 路径符号链接下可能空退出的问题；入口比较先解析真实路径。回归使用真实 tarball 和符号链接入口。

## 通过的检查

- Host/Client 发布构建、TypeScript 严格检查通过。
- 插件完整测试：18 个文件、163 项通过、1 项可选安装目录测试跳过。已显式启用真实 Semgrep 测试及真实语料基线检查；跳过项不计为通过。
- 工具/Skill 共存回归：另一插件注册通用 security 工具与 `security-review`，双方以两种顺序加载；卸载本插件仍保留对方注册。它验证命名隔离，不等于全部第三方插件版本的完整集成测试。
- uv 回归覆盖 TOML 多行字符串、schema/结构错误、规范化去重、多版本、工作区、Git/URL/缺版本、越界路径及不发送 registry 凭据。OSV HTTP 使用隔离模拟响应，不查询真实账号或私有依赖。
- 42 例真实 Semgrep 评测连跑三次结果一致；包含 4 个已知漏报与 6 个安全样例误报，不将它们隐藏为测试通过率。未测量 AI 复核、依赖公告数据库或密钥检测的准确率。
- 新增发布包测试通过：解包真实 tarball，在临时目录连接开发依赖用于解析；从符号链接运行 CLI，复跑评测与基线门禁（0/1/2 退出状态），再扫描含 uv.lock 的合成项目。子进程不含模型凭据，HTTP 被替换为严格的 OSV 假响应；评测阶段零 HTTP 请求，扫描报告无 Agent 审计记录。此测试依赖解析不是给用户的源码链接交付。
- catalog 兼容及公开导出测试 4 项通过；真实包身份、导出、依赖、固定兼容范围、大小及 SHA-256 与 catalog 对齐。公开导出测试同时验证：需要改写的包使用独立 `-public.1` 身份，已无内部主机名的包保留原身份与原字节，不覆盖不同内容的旧包。
- 分别使用开发 Node 26.7.0 和 App 内置 Node 24.19.0，通过官方插件安装命令将最终 catalog tarball 装入各自的临时 profile，启动官方 Web 入口。两次均正常注册 19 个工具和 2 个 Skills，授权页面与安全扫描 RPC 检查通过；此处验证实际安装后的依赖解析，不使用源码链接。
