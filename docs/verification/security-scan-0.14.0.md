# Security Scan 0.14.0 验证

日期：2026-11-06。环境：macOS arm64，官方 DSH 0.2.1-rc.5。

## 全局面板

- 安全扫描改用官方 `sidebar.panellist` 和匹配的 `main` 注册，侧栏负责按钮、折叠图标和选中状态。
- 主区域采用非模态工作台，不再限制用户访问侧栏；返回通过公开布局导航，报告深链仍限制为当前来源、当前页面和有效报告 ID。
- 任务、设置草稿在插件实例内保存。隔离浏览器夹具实测：修改任务名称后切换面板再返回，草稿恢复；显式返回仍提示未保存，放弃后草稿清除。修改报告目录后切换面板再返回，设置草稿恢复。检查期间控制台没有错误或警告。

## 检查结果

- TypeScript 类型检查与 Host / Client 发布构建通过。
- 插件测试 145 项通过、2 项跳过。跳过的是需显式提供真实 Semgrep 路径和目标安装目录的可选集成用例；不将跳过计为通过。最终导航测试单独复跑 4 项通过，覆盖标准面板登记、布局/会话导航、草稿实例与报告深链监听清理。
- catalog 与公开导出测试 4 项通过，包括真实仓库导出不包含 AIDEV 和内网 Git 主机名。
- 新 tarball 的包身份、版本、DSH 范围、大小和 SHA-256 与 catalog 一致。
- 分别通过开发 Node 26.7.0 和桌面 App 内置 Node 24.19.0，将 catalog 发布包安装到隔离 profile 并启动官方 Web 入口；19 个工具、2 个 Skills 正常注册，授权页面与安全扫描 RPC 检查通过。此检查未执行市场写操作或数据迁移。
- 通过现有导出脚本生成独立的公开预览，安全扫描包使用 `0.14.0-public.1` 身份；校验公开源码和压缩包内文件，不对外推送或发布。

界面交互使用合成任务，未调用模型、扫描真实账号数据或修改用户 profile。完整 `test:ui` Playwright 脚本未在本轮自动执行；本轮新增导航场景通过浏览器直接验证。Linux、Windows 和官方 Electron 桌面版未做本轮实机验收；上述通过结果不证明漏洞检出率或误报率。
