# Security Scan 0.18.0 验证

日期：2026-11-06。环境：macOS arm64；官方 DSH 0.2.1-rc.5；Semgrep CE 1.176.1。此记录不表示已更新任何现有用户安装；已安装用户执行 `dhp update` 换到该发布包。

## 变更

- 比较基线默认改为“上一次报告”：每次运行在排队时取同一任务最新的成功报告，优先覆盖完整的报告，跳过修复分支复扫和已删除的报告；没有时作为首次扫描并在报告中注明。去掉手动选择历史报告，0.17 中选了固定报告的任务和运行记录在读取时迁移。删除最新报告后改为对比更早的一份，不再因“被用作基线”而拒绝删除。
- 编辑器显示下次将对比哪一天的报告；运行记录可打开实际对比的报告，可比时显示新增数量，会话通知同步显示。
- 对话发起的扫描按目标、分支、范围和 Git 基线复用同一个任务，因此也会对比上一次；在工作台编辑过的任务不再被对话覆盖。同一目标正在扫描时返回已有运行，不再报错。
- 新增 `dsh_security_scan_findings` 与 `dsh_security_scan_exclude_findings`：修复会话核实误报后申请排除，经 DSH 原生审批卡片确认才写入，审批前先解析并展示问题、位置和原因。只接受本会话修复链、本会话发起或观察的扫描，以及当前工作区内本地扫描的报告；AI 补充发现、未知 ID 和其他会话的报告在审批前直接拒绝。
- 修复提示改为六步，加入“处理不修复的问题”；全部不修复且没有改动时不必复扫。安全审计预设放行修复与排除工具。
- 报告面板在修复开始后仍可手动标记误报，修复中的问题带标记，并每 5 秒同步会话里的排除与 PR 链接；“继续修复剩余问题”跳过已排除或已排除复核的问题。
- “报告初始筛选”只在有基线时显示；没有可比基线时报告默认显示全部问题。
- 安装说明改为从 npm 安装并写明版本号，Release 地址仍可用。
