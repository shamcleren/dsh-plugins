## 优化与回归

- submit_review 校验整批证据后再保存，集中返回中文说明、saved=false、问题类型、记录 ID、数组下标和文件行范围；失败批次不产生部分保存。
- 每次最多返回 20 个问题，omittedIssues 明确剩余数量。反馈不包含提交的源码、证据正文或密钥值。
- 密钥候选预先说明证据限制；read_evidence 返回 redactedLines 及核验建议，保持原有的脱敏和误报排除约束。
- 新增测试覆盖混合的未读引用/脱敏密钥问题、批次原子性、纠正后恢复以及反馈数量上限。
