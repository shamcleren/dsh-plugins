# 安全修复 PR 交付

版本：security-scan 0.13.0，DSH 0.1.7-rc.2。

## 行为

默认通过会话处理修复：建立独立本地分支和 worktree，修改并验证后向用户展示差异；能创建 PR 时优先建议 PR，没有平台工具、远端或权限则保留本地分支，用户最终决定是否提交、推送及创建 PR。点击修复本身不授予这些交付权限。仍可显式选择原有本地修改模式；旧修复记录继续按本地模式处理。

预览绑定仓库、当前分支与起点提交，拒绝脏目录、分离 HEAD 和起点变化，避免丢失用户改动或修错基线。远端条件不阻止本地分支修复，含凭据或不明确的远端不会展示。重试保留已有分支及修改，不自动删除 worktree。

插件不自带平台发布适配器或新凭据。PR 创建依赖对话中实际可用且已授权的平台工具。回填仅允许关联修复会话提交记录仓库的链接，不独立验证远端 PR 状态。复扫读取已记录的修复工作区并保留已回填的 PR 关联。

## 验证范围

- 隔离 Git 仓库：无远端也可创建修复分支、独立分支与子目录工作区、重试保留修改、原目录不变、脏目录拒绝、相同提交但目标分支变化拒绝、未知目录保护、远端及 PR URL 范围校验。
- 服务回归：PR / 本地模式冲突、会话身份绑定、链接回填、修复会话重复调用、复扫目标及报告仓库身份。
- 浏览器回归：默认会话修复、显式切换本地、仓库起点不满足条件时禁止发起、刷新预览、请求参数、PR 差异链接、修复分支复扫，保留原有批量选择及窄屏检查。
- 类型检查、插件测试通过、2 项跳过；发布构建及 catalog 包身份、导出、兼容声明、大小与摘要检查。
- `node scripts/smoke-runtime.mjs dist/runtime --startup-only` 在隔离 profile 安装发布包，验证真实 Host 注册 20 个工具（包含交付回填）、2 个 Skill、Codex provider，以及认证 Web 页面和安全扫描 RPC。

尚未执行真实账号下的提交、推送及工蜂/GitHub 草稿 PR 创建；不能把模拟会话或启动验证当作平台交付验收。上一轮完整 smoke 的旧配置迁移超时仍未定位，`--startup-only` 明确不验证迁移与市场写入，不替代完整 smoke。
