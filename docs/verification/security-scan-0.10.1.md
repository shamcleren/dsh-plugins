# Security Scan 0.10.1 验证

2026-09-11，macOS arm64，官方 DSH 0.1.0-rc.8。

## 模型选择

- 使用公开的 `llm.listProviders()` / `llm.listModels()`，通过独立 loopback RPC 返回模型与服务商显示名称，不传递设置、密钥或请求头，不随两秒任务状态轮询重复查询。
- 下拉默认跟随 DSH 默认模型；明确选择同时保存 provider/model。旧任务的未列出模型保留并提示，不将目录缺失当作路由无效。支持空列表、部分失败、刷新和卸载后的异步结果丢弃。
- 真实安装包在隔离 Host 上加载，额外测试 patch 注册两个不会生成内容的模拟 provider。相同模型 ID 在不同 provider 下可以区分；从 UI 选择、保存、重新编辑后准确保留。切回默认并保存后，持久化文件中的 provider/model 均为空。
- 回归覆盖公开字段投影、部分目录失败、空目录、同 ID 不同路由、未列出旧选择、RPC 参数校验、可选服务注入作用域，以及保存/恢复默认。未调用真实模型或修改用户凭据。

## 界面

- 合并工作台重复样式，统一输入框、原生下拉框和按钮为 40px；表单控件实测 14px 字号。显式移除原生 select 外观，统一边框、圆角、内边距、焦点和禁用状态。
- 检查任务列表/编辑、运行记录、历史报告、报告预览、扫描设置、Git hooks 和删除报告确认框。确认框仅检查展示与取消，没有操作真实报告或仓库 hook。
- 浅色桌面、深色 720px 窗口及 390px 窗口实测。编辑页 9 个输入/select 控件均为 40px，设置页 3 个输入框和 hook 确认中的 2 个 select/1 个 input 同高。390px 下主区域没有横向溢出；表格保留独立横向滚动，操作按钮可换行。推送前 hook 缺少基线时确认按钮禁用。
- 模型列表刷新按钮、表单主次按钮、危险操作、提示文字和主题前景色沿用统一样式；恢复浏览器临时视口与颜色模拟后关闭测试页。

## 验证结果与范围

- TypeScript 与构建通过，94 项插件回归全部通过，无跳过，含真实 Semgrep 和安装包的官方 profile 加载。
- 通过真实 `dhp --dir <隔离安装> plugin install security-scan` 安装后启动官方 Web profile；最终包 78 个文件与构建目录、隔离安装逐文件一致，package.json 按 JSON 内容比较。大小/SHA-256 与 marketplace.json 一致。
- 沙箱内启动的 DSH 文件监听报 EMFILE，改在沙箱外启动同一隔离测试服务。核实崩溃进程已结束后，仅清理该测试实例遗留的锁。3198 服务验证后停止。
