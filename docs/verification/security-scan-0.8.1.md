# Security Scan 0.8.1 主题修复验证

2026-09-10，macOS arm64，官方 DSH 0.1.0-rc.8。

原因：主按钮背景采用 `--dsw-alias-brand-primary`，但文字固定 white；DSH 深色主题的主色为浅色，因此出现白底白字。改用配套 `--dsw-alias-label-primary-foreground`，同时定义仅对非禁用按钮生效的悬停 / 按下色。源码面板及 AI 标签也使用主题语义色。

0.8.1 发布包装入已归属的独立 profile，3198 正式 Web 入口启动。通过原生设置依次选择深色、浅色，并读取工作台新建任务及全部立即扫描按钮的浏览器计算样式：

- 深色：背景 rgb(249,250,251)，文字 rgb(15,17,21)。悬停背景变浅灰，文字仍深色。
- 浅色：背景 rgb(15,17,21)，文字 rgb(255,255,255)。悬停背景变深灰，文字仍白色。
- 禁用态保留既有半透明处理，新的 hover/active 规则不匹配禁用按钮；未为验证禁用态发起真实扫描。

TypeScript、服务端 / 客户端构建通过；相关 client-entry / workflow 12 项测试通过。包内 64 文件与构建及测试安装内容一致，marketplace 大小和 SHA-256 核对通过：c1f364941c4f43d0085e4f1aad2caae85b13ab5781e7812d0d8ba0ebb5504b25。
