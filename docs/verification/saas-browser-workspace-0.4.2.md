# SaaS Browser Workspace 0.4.2：通用页面 Panel

日期：2026-11-23。宿主兼容范围保持官方 0.2.1-rc.5，复用公开 BrowserService、原生会话队列、GenUI 和右侧面板扩展，不修改官方源码。

## 变更

- 通用 DOM/ARIA 页面结构：字段组、正文、表格、列表、说明项；展示不需要查询选择器。
- 明确区分空值、未读取、隐藏、选中与开关状态；修正模式选项被误作配置值和原生 select 选项无法读取的问题。
- 折叠区、图形、复杂编辑器、iframe、Shadow DOM、未归类内容与读取上限均提示原页面；无结构时默认只读截图，旧观察也可回退。
- 只有一个查询入口，表格、列表、汇总是该结果的内部视角。
- 页面原文默认折叠；快照来源不同或浏览器不可用时不展示误导性的当前画面。

## 验证状态

- 9 个测试文件、60 项测试通过；TypeScript 严格检查和服务端/客户端构建通过。
- 真实 Chromium 验证原生与 ARIA 字段、空值与未读状态、占位提示、模式选项、字段分组、HTML 表格/列表、折叠/图形/编辑器/嵌入内容提示、敏感信息过滤及大页面读取上限。
- 400px React/GenUI 面板验证单查询入口与布局切换、结构卡片、只读画面兜底、旧观察兼容、来源变更、断连、键盘退出，以及页面字符串不能执行脚本。
- 确切 catalog tarball 经官方 CLI 安装到隔离 Web profile，真实模型完成补参→查询→选择→配置→调试→去使用。新结构字段包含真实 DOM 模型值；两种模式各收到一次测试 POST、各返回 `42`，保存次数为零。截图鉴权和敏感字段过滤同时通过。此流程使用本地合成网站。
- 首轮全套断言通过但测试服务的长连接清理超时，修正资源关闭后完整退出通过；首次整包验收发现测试事件文件写入与读取竞争，改用原子替换后整包验收通过。没有用重试或放宽断言代替修复。
- 按用户授权，仅更新本地正式安装中的 SaaS catalog 包，并重启原有 macOS 应用。安装前备份，安装后校验另外 7 个插件、profile 配置、站点配置和凭据均未改变；界面已确认正常加载并准备接收任务。重启后不声称恢复浏览器现场，真实账号配置页的改版效果仍待重新发起任务验证。

## 范围与限制

结构测试使用不同布局的本地 HTML/ARIA 合成页面；它们验证展示规则和读取边界，不能证明任意真实网站都可准确重绘。复杂编辑器不读取私有模型或跨 frame 内容，依靠原页面画面。新站点的来源、登录和自动操作仍需逐站授权与验证。没有新增业务配置保存或发布能力。
