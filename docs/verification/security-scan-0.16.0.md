# Security Scan 0.16.0 发布候选验证

日期：2026-11-06。环境：macOS arm64；官方 DSH 0.2.1-rc.5。此记录对应本地发布候选，不表示已对外发布或更新现有用户安装。

## 变更

- 新增可选的只读运行时基线检查：只对用户填写并勾选授权的 HTTP(S) 地址发送最多 12 个同源 GET 请求，检查安全响应头、Cookie 属性、CORS、调试错误页、目录索引及 `.git` / `.env` / pprof / Werkzeug 控制台暴露。不登录、不提交表单、不发送攻击载荷，不是完整 DAST。CLI 为 `--dynamic URL`，对话工具为 `dynamic_url`。报告不保存响应正文或 Cookie 值；SARIF 以端点 URL 作为位置。
- 运行时发现不参与静态基线可比性、扫描器版本匹配及证据归档，旧报告作为静态基线仍可比；运行时增减只与同一地址的上一次完整检查比较。服务不可达时仅该项失败、覆盖标为不完整，扫描任务仍为成功并发布静态结果。
- 修复闭环：修复会话提示改为核实、最小修复、回归验证、复扫、总结五步，并附按类别整理的修复要点。新增会话专属工具 `dsh_security_scan_repair_rescan`，排队一次复扫，复扫未结束时重复调用复用同一记录，结果回到同一修复会话。复扫报告可“继续修复剩余问题”，按稳定指纹带上原选中问题及新增问题，每轮最多 20 项。
- 界面：任务编辑按代码来源、范围与基线、检查项、修复与自动化分组，检查项改为卡片并标明哪些不消耗模型 Token；任务卡片显示最近一次运行的问题与复核计数；运行记录显示“修复复扫”触发；报告面板新增 选择 → 修复 → 复扫 → 对比 进度、按已确认 / 高危快捷选择、运行时端点展示与继续修复入口。

## 验证边界

运行时检查只在本机回环服务上验证，未对真实部署、网关或 CDN 执行；HTTPS 相关规则（HSTS、Secure Cookie、明文传输）由单元测试覆盖逻辑，未连接真实 HTTPS 服务。修复闭环使用模拟的原生会话接口验证排队与轮次，未调用真实模型完成一次端到端修复。未发送真实 OSV 请求、迁移真实用户数据或更新用户 profile。运行时检查只用官方 Web 入口验证，不代替官方 Electron 桌面 UI、Linux 或 Windows 实机验收。

代码、最终归档和 catalog 已准备在工作区，未提交、推送或执行外部发布。
