# Security Scan 0.3.0 验证

日期：2026-09-10；macOS arm64；官方 DSH `0.1.0-rc.8`，未修改上游。

## 通过

- 类型检查、服务端及浏览器构建通过。冻结锁文件安装通过，新增依赖限定在安全扫描组件。
- 插件 35 项测试通过，1 项真实 Semgrep 测试跳过。包含安装后 profile 合成、独立客户端插槽、任务持久化与修订冲突、队列与取消、进程重启中断、锁归属、RPC 输入和 hook 确认、编辑后触发、历史报告兼容及报告目录错误恢复。
- 根工程安装器和插件管理脚本 45 项测试通过。
- `0.3.0` tarball 安装到临时独立 profile，真实 Web Host 启动；浏览器显示侧边栏「安全扫描」入口。通过官方 additive sidebar/overlay 插槽打开独立工作台，无需进入设置，也不替换对话页。
- 浏览器完成本地任务新建、保存并运行、编辑、扫描设置保存、运行记录查看、取消正在执行的扫描。盘点任务生成 JSON，工作台内 sandbox iframe 显示 HTML，截图检查布局。
- Host 正常关闭后释放任务存储锁；重新启动保留任务、运行记录和历史报告。「返回 DSH」恢复原界面及入口焦点。
- 浏览器从任务进入 Git hooks 表单，明确确认后在隔离样例仓库安装 pre-commit；文件包含本插件归属标记及该仓库、扫描器和报告目录。未对用户仓库安装 hook。
- 核对官方编辑工具默认名称 `write`、`edit` 和 `str_replace_editor`；新增回归验证写操作触发、编辑器只读 `view` 不触发。

## 范围

本次 UI 验收用文件盘点模式验证完整任务和报告链路，用自有延迟扫描器夹具验证取消。没有将夹具结果解释为漏洞扫描质量验证，也没有进行真实模型审计。实际 Semgrep/Gitleaks/OSV 和 Git hook 执行的既有验证见 [0.2.0 记录](security-scan-0.2.0.md)，本次未重复那些外部引擎验收。

工作台手动任务和自动编辑任务运行规则扫描；模型复核仍在 DSH 会话中使用 `security-review`。Git hooks 只执行 Semgrep，不继承任务的依赖查询或密钥检测开关。

所有测试安装、任务、配置和 hooks 使用独立临时目录与端口。未更新用户当前 App、profile、模型或市场账户。Host 在允许原生文件监听的执行环境运行；未调整系统限制或修改官方监听代码。
