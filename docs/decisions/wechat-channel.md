# 微信加载即接收与开放聊天

0.4.0 将插件加载作为消息接收生命周期入口。授权仍由扫码完成；凭据存在且含扫码者身份时，加载后自动开始接收所有已绑定账号。二维码完成只保存授权并触发运行时协调，不再依赖额外设置写入。停止通过卸载/停用插件或退出 Host 完成，已有授权保留。

按用户明确选择，普通聊天不设置 ID 白名单。扫码身份只用于自动确定管理者；管理命令不授予其他聊天者，其工具审批交给原有 Host 审批处理，不能在微信侧自行同意。退休的 enabled、accountIds、allowedUsers、adminUsers 字段不影响新运行行为。其他既有执行参数继续兼容。用户界面保留绑定和状态操作，并按 [Channel 默认模型与预设](channel-default-policy.md) 提供渠道预设下拉；具体默认值以插件 README 为准。

默认工作区放在独立 workspaces/wechat 目录，凭据继续存放 channels/wechat；不迁移已有 session、覆盖自定义工作区或把凭据目录作为新聊天的工作区。接收服务状态和授权状态分别显示，运行中表示本机轮询服务已启动，不冒充上游连接成功。
