# 安装锁恢复

安装目录和共享数据目录继续使用私有 PID 文件，兼容旧安装器及启动入口的忙碌检查。更新只在持有者明确不存在时恢复旧锁；PID 仍存在（包括复用）、权限不足或格式未知时拒绝恢复。已确认失效的文件保留为同目录备份。

“检查 PID 后直接删除文件”不能避免两个恢复者互删新锁。因此新安装器先持有一个按规范化锁路径确定的本机回环 TCP 租约，并在整个写入操作期间保留。租约由内核持有，进程异常退出后释放，避免再引入一个也可能残留的文件恢复锁。不同路径碰撞时，只有识别到另一条 DHP 租约才尝试其他槽位；未知服务拒绝继续。租约只返回协议标识和路径摘要，不提供管理操作，也不传输配置或凭据。

PID 文件先完整写入随机临时文件，再用排他硬链接发布，避免进程在写入前退出而留下空锁。释放时核对 inode 及内容，只移除本次持有的文件。bootstrap 的共享目录锁释放失败时，仍会释放安装目录锁。

回归使用隔离目录，覆盖进程强制退出后的双锁恢复、跨进程恢复竞争、活进程和未知状态拒绝、异常文件保留、路径槽位碰撞及替换锁不被清除。实际运行时和用户 profile 的迁移另由既有更新事务负责。
