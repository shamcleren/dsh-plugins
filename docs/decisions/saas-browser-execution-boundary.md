# SaaS 浏览器对话执行边界

## 决定

通过独立插件给真实 Agent 提供观察、导航、补参及受限聊天发送能力，继续复用官方浏览器服务、会话队列、表单和右侧扩展点，不修改宿主源码。

模型决定操作次序；站点配置决定可操作的来源、路径和聊天控件。默认禁止发送，只有显式登记的调试或使用容器可输入消息并提交，配置字段及保存、发布等控件始终拒绝。使用窗口继承同一来源策略，初始 HTTP 地址仅能升级到已授权的 HTTPS 后再校验入口。

发送与结果读取分离。发送前持久化唯一执行标识；浏览器读取本次新增回复形成结果，模型文本不能写入执行结果。未确认的提交不自动重发，重启前未结束的收据恢复为待确认。

## 影响

获得可核对的真实执行与重复提交保护，代价是站点执行区域需要实际验证与维护。收据恢复不等于浏览器或整个任务恢复；结果判定仍依赖原页面的回复、运行和错误状态。真实账号的对话记录及费用由原站点管理。
